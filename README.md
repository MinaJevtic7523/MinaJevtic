# Mina Jevtić – Portfolio

Personal portfolio website of Mina Jevtić, web developer from Belgrade, Serbia.

## Sections
Home, Skills, Services, Projects, About and Contact, with a scroll progress bar and a downloadable CV (`access/cv/Mina-Jevtic-CV.pdf`).

## Technologies
- HTML5
- CSS3 and Sass (source in `scss/`, compiled to `access/css/`)
- Font Awesome icons and Google Fonts
- SEO files: `robots.txt` and `sitemap.xml` in `access/`

## Run locally
No build step is needed. Clone the repo and open `index.html` in a browser.

```bash
git clone https://github.com/MinaJevtic7523/minajevtic.git
cd minajevtic
```
