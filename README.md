# Mina Jevtić – Portfolio

Personal portfolio website of Mina Jevtić, web developer from Belgrade, Serbia.

## Sections
Home, Skills, Services, Projects, About and Contact, plus a downloadable CV (`access/Mina-Jevtic-CV.pdf`).

## Technologies
- HTML5
- CSS3
- JavaScript (mobile menu, scroll progress bar, contact form)
- Local fonts (Karla and Libre Baskerville), no external dependencies
- SEO files: `robots.txt` and `sitemap.xml`

## Run locally
No build step is needed. Clone the repo and open `index.html` in a browser.

git clone https://github.com/MinaJevtic7523/MinaJevtic.git
